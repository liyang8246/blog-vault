## 前言

最近到深圳上班, 把老爸的风行412抢过来骑了, 基本都是骑出去几十公里然后折叠提上地铁坐回来, 不得不说深圳对折叠车挺友好的, 不需要套车袋 ~~当然最好还是套上~~ 就能直接过安检上地铁

但是风行412折好后既不能推行, 又松松垮垮, 进出站和换乘体验极差, ~~练完下肢练上肢说是~~, 每次搬自行车的时候想买小布的心都到了极点. 不过英国原产小布太贵了 ~~而且我不需要他的社交属性~~, 于是目光放在了国产小布身上, 恰巧几家做的比较好的小布厂家都在深圳有线下店, 于是决定全都去试骑一圈再决定买哪个.

我的需求很明确:
- 设计近似 1:1 英布, 改装/维修件通用
- 112/74 开档 16 寸轮组
- 预算范围比较宽, 让我觉得物有所值就行
- 最好做工能好点

## Aceoffix

本来没想着去 ace 的, 因为他的 c5 太贵了我觉得 7.5k 还不如加点钱上 cline 了, 但是发现店就开在吃早餐的店旁边, 那就顺便看一看了.

c5 真的很轻很好骑, 7.5KG 一蹬就走, 变速灵敏, 刹车也能轻松抱死轮子, 折叠手感也好. 仔细看, 车漆质感和焊接点也无可挑剔, 感觉应该是 c 刹国布里最好的车子了吧.

硬要挑缺点, 感觉它的上梁比较粗一点, 提车的时候不是很好发力的感觉. 而且它是出厂不带货架挡泥板的(7.5KG的代价), 这让他的推行体验比较一般, 得翘起来推才比较顺滑. 而且后架卡扣有点框量(我不知道这是不是无法避免的, 不过他也是这天体验下来所有品牌框量最小的)

不过我还是觉得 7.5k 太贵了, 加上货架挡泥板估计得 8k+ 了.

## Java

虽然我一开始就没打算买 java(因为他是碟刹不符合我要求), 但是我真的很好奇他的中轴后置骑起来到底什么感觉, 于是就去找了家顺路的店看看(java 线下店的密度是真的高)

~~老板好像把他自己骑的 java neo 借给我骑了~~ 一上车就觉得不对, 很别扭 特别别扭, 小红书上都说这是公路车几何, 但我觉得完全不一样, 中轴后置的感觉特别奇怪, 说不上来, 骑了几十米就没骑了, 如果你打算买 java 三折叠, 请一定要线下体验一下再决定买不买.

## Mint

顺着地图找米特, 结果店门招牌挂的大行, 再三确认后问了下老板才确认, 这家店也卖 mint. 其实一开始的目标是 mint bob5, 他既有超低的价格, 又有bob7同款车架. 即使初始配置不改, 但是花点小钱改一改应该就能很好骑, 而且 5 速对我来说也够用. ~~但是好像各家mint的老板都不是很愿意卖bob5~~, 可能是利润太低了.

试骑的是bob7pro, 起步能明显感觉到比 ace 重一点, 但是骑起来就没什么感觉, 变速虽然赶不上 ace 那么好用, 但我觉得没什么毛病还挺好的. 但有个很大的问题是即使我用尽力气捏紧刹车, 都不说抱死车轮了, 我感觉它的制动力完全就不合格, 差的有点离谱了, 不清楚什么原因, 可能是样车装配问题吧? 再差再便宜的刹车件应该也不至于这么差表现.

做工上, 我觉得并没有网友说的那么不堪, 我觉得做得其实挺好的, 漆水焊点感觉都是正常水平, 没看到什么瑕疵的情况. 而且我发现他的 c 扣是带限位的, 这个细节做的比 ace 好. 唯一发现不对的就是那辆样车的前后挡泥板都有点歪, 以及变速指拨没装紧, 都是装配问题.

总体我觉得还是挺好的, 钢架碳叉算是一步到位了, 关键价格实在.
后续我买的也是 bob7pro, 找的我爸的老熟人买的, 升级了下 刹车皮 马牌胎 镂空曲柄牙盘, 价格真挺优惠的

## 佰客

在试骑之前, 我的买车意向最高的其实就是佰客sepro和青春se, 但是试骑的时候让我大跌眼镜

试骑的是 sepro, 变速是有问题的, 最大的两片飞轮挂不上去, 刹车还算合格, 但也是用尽力气抱不死(~~不懂圈刹抱死车轮这么难做吗, 我现在骑的 412 都能轻松一捏抱死~~), 而且指拨角度极其诡异, 几乎需要改变右手握姿才能够到拨杆, 店员说小布就是这样的不然影响折叠(但我看未必, 前面试骑的都没这个问题), 试骑完发现链条掉到了张链导轮外(可能是这个原因导致大飞挂不上). sepro同样不自带货架挡泥板, 加装铝合金货架需要 450 元.

然后又试了试 14 寸的 nano, 这辆车一给我的时候他的链条就是掉到张链导轮外边的... 骑起来感觉也不错, 可能由于轴距比较长, 总体感觉比 412 要好点. 但是同样的, 指拨角度极其诡异.

做工方面, 没看出来比mint有啥肉眼差距, 不过感觉推起来的手感挺好的.

值得一说的是佰客的坐管是限位坐管, 不仅是有高度限位, 还有角度限位, 真的很方便. 不知道其他品牌的车能不能改他这个坐管, 我看淘宝有单独卖
