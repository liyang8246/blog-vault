## 选型理由

- **RV1103G1**: ¥20 内唯一带硬件 H.265 + PHY
- **IT66021FN**: HDMI 1.4b 转 BT.656, 够便宜主要是
- **STM32F072**: 只做 HID, 其实随便选一个都行

## 系统架构

```
被控机 HDMI ─→ IT66021FN ── BT.656──→ RV1103G1 ──H.265──→ 100M PHY ─→ RJ45 ─→ 浏览器
                                      │ SD 卡(ISO 库)
                                      │ UART(键鼠命令)
被控机 USB ←──1 线──→ CH334 Hub ──┬── STM32F072(HID 键鼠,独立于 Linux)
                                  └── RV1103 USB gadget(MSC 光驱)
F072 GPIO → 光继电器 → 被控机 PWR/RESET
```
